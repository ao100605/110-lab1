Lemonade Stand user stories:
- As a player, I want to be able to type my answers so that I can insert my decisions
- As a player, I want clear prompted questions with current prices so that I am clear on what number to enter.
- As a player, I want my current asset and cost of lemonade to be shown at the start of each day so that I can make more suitable decisions.
- As a player, I want to see the financial report after each day so that I know the result of my choices.
